**AWS Batch** is a **fully managed batch computing service** that efficiently runs **large-scale batch jobs** without you having to provision or manage compute infrastructure.

It is designed for **compute-intensive, non-interactive workloads** that run in the background.

## What AWS Batch Is
AWS Batch allows you to:
- Submit **batch jobs** (jobs that run to completion)
- Automatically provision the **right compute resources**
- Run jobs at **any scale**
- Optimize cost using **Spot and On-Demand instances**
In short: **you submit jobs, AWS Batch decides where and how they run.**
