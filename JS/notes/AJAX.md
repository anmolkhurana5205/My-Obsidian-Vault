AJAX stands for **Asynchronous JavaScript and XML**.  
It’s not a programming language, but a **technique** used in web development that allows web pages to update content **without reloading the entire page**.

For example:

- When you scroll through Instagram and new posts load automatically.
- When you search on Google, and results appear while you type.
- When you “like” something on Facebook, the like count updates instantly.

All of this is possible because of **AJAX**.
